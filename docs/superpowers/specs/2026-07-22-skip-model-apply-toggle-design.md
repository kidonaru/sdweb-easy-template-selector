# テンプレート適用時のモデル反映トグル 設計

日付: 2026-07-22

## 目的

テンプレート適用時にチェックポイント（モデル）の切り替えをスキップできるトグルを UI に追加する。モデル切り替えは時間がかかるため、プロンプトや他のメタ情報だけ反映したいケースに対応する。

## 仕様

- ヘッダー部（保存ボタン付近）に「モデル反映」チェックボックスを追加する。
- デフォルトはオン（モデルを反映する）。
- 状態はメモリ保持のみ（セッション限り）。UI リロードでオンに戻る。永続化はしない。
- オフのとき、テンプレート適用時の `selectCheckpoint(modelName)` 呼び出しをスキップする。
- テンプレート保存側（`Model` メタの書き出し）は変更しない。

## 変更対象

| ファイル | 変更内容 |
|---|---|
| `javascript/ets_template_manager.js` | `applyModel` フラグ（初期値 `true`）とセッターを追加。`applyTemplate()` 内の `selectCheckpoint` 呼び出し（現行 126-132 行）を `this.applyModel` が真のときだけ実行 |
| `javascript/easy_template_selector.js` | ヘッダーに `ETSElementBuilder.checkbox('モデル反映', true, { onChange })` を追加し、変更時にフラグを更新 |

## 影響範囲

- `applyMeta` の `Model` 反映は元々コメントアウト済みのため触らない。
- pnginfo 経由の apply ボタン処理はそのまま（モデル切替は明示的な `selectCheckpoint` のみで行われている）。

## テスト方針

ビルド・テスト基盤はないため WebUI / reForge 上で手動確認する。

1. トグルオン（デフォルト）でテンプレート適用 → モデルが切り替わる。
2. トグルオフでテンプレート適用 → モデルは切り替わらず、プロンプト・Steps 等のメタは反映される。
3. UI リロード後 → トグルはオンに戻る。
