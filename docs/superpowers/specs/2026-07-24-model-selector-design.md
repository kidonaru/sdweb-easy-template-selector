# 90_モデル.yml モデル選択機能 設計書

日付: 2026-07-24

## 概要

`96_解像度.yml` と同様の特殊カテゴリとして `tags/90_モデル.yml` を追加する。
モデルボタンを押すと、プロンプトへのタグ挿入は行わず、以下を実行する:

1. チェックポイント(モデル)の切り替え
2. ポジティブ/ネガティブプロンプト内の `# 01_クオリティ:Model` / `# 99_ネガティブ:Model` セクションを、選択モデルに対応するタグ列へ差し替え

## タグファイル

### `tags/90_モデル.yml`(新規)

ベースモデル系列でグルーピング。キー=表示名、値=チェックポイント名(`selectCheckpoint` に渡す値)。

```yaml
Illustrious:
  "WAI-illustrious-SDXL v17.0": waiIllustriousSDXL_v170
SDXL:
  # 既存モデルを追記
```

### `01_クオリティ.yml` / `99_ネガティブ.yml`(既存修正)

`Model:` サブカテゴリのキーを `90_モデル.yml` の表示名と**完全一致**にリネームする。
対応付けは表示名の完全一致のみで行う(マッピングテーブルは持たない)。

## 実装

### `ets_section.js`

- `isModelCategory()` を追加: `this.category.startsWith('90_モデル')`。

### `ets_prompt_editor.js` の `addTag`

解像度分岐と同様に、モデルカテゴリなら early return する分岐を追加:

1. **モデル切り替え**: `templateManager.getCurrentModel()` と異なる場合のみ `selectCheckpoint(値)` を実行。
   `applyModel` フラグはテンプレート適用専用のため参照しない(ボタン押下は明示操作)。
2. **Model セクション差し替え**:
   - 読み込み済みタグデータの `01_クオリティ` → `Model:` 配下から表示名一致のタグ列を取得。
   - ポジティブプロンプトに `# 01_クオリティ:Model` で始まるセクションが**存在する場合のみ**、
     コメントを表示名に、タグ行を新タグ列に差し替える。存在しなければ何もしない(新規追加しない)。
   - `# 99_ネガティブ:Model` も同様にネガティブプロンプト側で処理。
   - 対応する `Model:` エントリが無いモデルはモデル切り替えのみ行う。
3. 差し替えを行った場合は `saveTextHistory` で履歴に記録し、Undo 可能にする。

セクション検索は既存のサブカテゴリマッチ(`# 01_クオリティ:Model` ヘッダー前方一致)を利用する。

## エラーハンドリング

- `selectCheckpoint` 未定義(WebUI バージョン差異)の場合は console にエラーログ(日本語)を出して中断。
- 表示名に対応するチェックポイントが WebUI に無い場合は `selectCheckpoint` の挙動に委ねる(既存テンプレート適用と同等)。

## テスト方針

ビルド基盤が無いため reForge 上で手動確認:

- モデルボタン押下でチェックポイントが切り替わる
- Model セクション有り: ポジ/ネガ両方が差し替わる
- Model セクション無し: プロンプトが変化しない
- `01/99` に対応エントリが無いモデル: モデル切り替えのみ
- 差し替え後に Undo で復元できる
- 現在と同じモデルのボタン押下: チェックポイント再読込が発生しない
