# create-template

入力プロンプトを Easy Template Selector のテンプレート形式（pnginfo 互換 .txt）へ変換するスキル。
テンプレートの各行はカテゴリコメント + タグ行のペアで構成され、コメントは JS パーサ
（`ets_prompt_editor.js` / `ets_section.js`）が解釈するため、形式を厳密に守る必要がある。

## テンプレート形式（厳守）

```
# URL: <出典URL>,            ← 出典があれば先頭に（任意）

# <カテゴリ>:<グループ> (<日本語ラベル>),
tag1, tag2,
# <カテゴリ> (<日本語ラベル>),
tag,
...
Negative prompt: # 99_ネガティブ:<グループ> (<ラベル>),
<ネガティブタグ列>,
Steps: 25, Sampler: DPM++ 2M, ... （メタデータ行）
```

ルール:
- `<カテゴリ>` は `tags/` の YAML ファイル名から拡張子を除いたもの（例: `23_表情`、`10_キャラ_ブルアカ`）。
- `<グループ>` は YAML 内のトップレベルキー（例: `基本`、`絵文字`）。グループが無いフラットな YAML では `:<グループ>` を省略。
- `(<日本語ラベル>)` は YAML 内でそのタグに付けたキー（日本語ラベル）。コメント行は必ず `,` で終える。
- タグ行も `,` で終える。
- セクションの並びはカテゴリ番号昇順（01 → 02 → 10 → … → 70番台）。01_クオリティ系を先頭、スタイル/LoRA 系（70番台）を末尾に置く。
- `Negative prompt:` 行以降がネガティブ、`Steps:` で始まる行以降がメタデータとして解釈される。
- メタデータ行は既存テンプレート（同系統の templates/ 内ファイル）からコピーして流用する。Seed は `-1` にするか既存値のままで良い。

## 手順

1. **入力の解釈**: 入力プロンプトをタグ（またはシーン要素）に分解する。日本語説明の場合は Danbooru 系タグへ変換する。
2. **既存タグの照合**: 各タグについて `python tools/search_tags.py <検索語...>` で検索し、既存エントリがあればそのファイル名・グループ・日本語ラベルをコメントに使う（出力がそのままカテゴリコメント行の形式）。`tags/` は `.gitignore` 対象のため Grep ツールでは検索できない。表記ゆれ（スペース/アンダースコア）が疑われる場合は既定の部分一致のまま探し、"arch" のような短い語で無関係な結果が大量に出る場合は `--exact` を付けて絞り込む。
3. **不足タグの追加**: 見つからないタグは、意味的に最も近いカテゴリの YAML の適切なグループへ、日本語ラベル付きで追記する。
   - ファイル命名規則 `番号_カテゴリ名[_サブ分類].yml` と番号帯（01=クオリティ、10番台=キャラ/衣装、20番台=表情、30番台=ポーズ、40番台=アングル、50番台=背景、60番台以降=効果/その他、99=ネガティブ）を守る。
   - 既存ファイルに収まらない場合のみ新規 YAML を作る（番号帯を合わせる）。
   - 追記後は `python -c "import yaml, sys; yaml.safe_load(open(sys.argv[1], encoding='utf-8'))" tags/対象.yml` で構文確認する。
4. **テンプレート組み立て**: 上記形式でセクションを並べ、クオリティ・レーティング・ネガティブ・メタデータは同系統の既存テンプレートから流用する（入力に指定があればそちらを優先）。
5. **保存**: 内容が SFW なら `templates/01_SFW/`、NSFW なら `templates/02_NSFW/` に、内容を表す日本語ファイル名（例: `夕暮れの屋上 制服.txt`）で UTF-8 保存する。
6. **報告**: 作成したテンプレートのパス、流用したタグ、追加したタグ（追記先 YAML とラベル）を一覧で報告する。

## 例

入力: `1girl, sitting on bench, autumn leaves, scarf, gentle smile`

- `1girl` → `02_対象` に既存（一人の女の子）→ 流用
- `sitting on bench` → `30_ポーズ` を検索、無ければ `30_ポーズ.yml` の適切なグループに `ベンチに座る: sitting on bench` を追記
- `autumn leaves` → `50_背景` 系に無ければ追記（例: `紅葉: autumn leaves`）
- `scarf` → `14_衣装小物` に既存なら流用
- `gentle smile` → `23_表情` の `基本` グループへ追記

出力（抜粋）:

```
# 01_クオリティ:Model (Nova Anime XL),
masterpiece, best quality, ...,
# 02_対象 (一人の女の子),
1girl,solo,
# 14_衣装小物 (マフラー),
scarf,
# 23_表情:基本 (優しい微笑み),
gentle smile,
# 30_ポーズ:基本 (ベンチに座る),
sitting on bench,
# 50_背景:自然 (紅葉),
autumn leaves,
Negative prompt: # 99_ネガティブ:Model (Nova Anime XL),
...（既存テンプレから流用）
Steps: 25, Sampler: DPM++ 2M, ...（既存テンプレから流用）
```

## 注意

- コメント行の形式が崩れると UI 上でセクション分解できなくなる。必ず `# カテゴリ[:グループ] (ラベル),` 形式にする。
- 既存 YAML の既存エントリは変更しない（追記のみ）。
- タグの重複追加をしない: 追記前に必ず `tools/search_tags.py` で該当タグを検索する。
- LoRA タグ（`<lora:...>`）は 70 番台のカテゴリを使う。入力に無ければ追加しない。
