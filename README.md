# Easy Template Selector

[Easy Prompt Selector](https://github.com/blue-pen5805/sdweb-easy-prompt-selector)
の改造版です。

独特なプロンプトの書き方をすることで、キャラの変更などを容易にできるようにしています。

https://github.com/user-attachments/assets/bdbc3e6c-161f-498f-96c7-950938b90c3a



# インストール方法

WebUI・reForge・Forge Neo で動作確認しています

WebUIの`Extensions` - `Install from URL`に以下のURLを入力してインストールしてください。

```
https://github.com/kidonaru/sdweb-easy-template-selector
```

# 機能

## テンプレートの読み込み/保存
- `templates`ディレクトリ以下にpnginfoを`.txt`で保存しておくと、`00_テンプレート`に表示され、読み込むことができます
  - プロンプトとメタ情報を読み込んで反映します
- `💾`ボタンを押すと現在のプロンプトとメタ情報を`templates`ディレクトリ以下に保存することができます
  - 既存のテンプレートを上書きすると拡張機能の更新に失敗することがあるので、別名で保存することを推奨します
- テンプレートは階層構造で管理可能（例：`templates/03_Test/てすと.txt`）

## プロンプトの構造化
- プロンプトをカテゴリごとに分類して管理しています
- *タグを追加すると、既存のカテゴリを自動で上書きします*
  - 単純な追加は`Ctrl`キーを押しながら行うと、既存のカテゴリを上書きせずに追加できます
- ネガティブプロンプトも同様に管理可能 (`99_ネガティブ`カテゴリは自動的にネガティブプロンプトに反映)

### プロンプトサンプル

```
# URL: {{プロンプトの参考URL}},

# 01_クオリティ:Model (Nova Anime XL),
masterpiece, best quality, amazing quality, very aesthetic, high resolution, ultra-detailed, absurdres, newest, scenery,
# 02_対象 (一人の女の子(強調)),
1girl,solo,
# 10_キャラ_ブルアカ:トリニティ (カズサ),
kazusa \(blue archive\),red eyes,black hair, animal ears,halo,choker,(hooded jacket:1.1),
# 50_背景_基本:基本 (屋外),
outdoors,
```

タグボタンを押すと
```
# {{カテゴリ}} ({{タグ名}}),
{{プロンプト}},
```
というフォーマットでプロンプトに反映されます

## アンドゥ/リドゥ機能
- プロンプトの変更履歴を保持
- 最大20件の履歴を保存

## マウスオーバーでタグの中身を表示
- タグ名にカーソルを乗せると、そのタグの内容をツールチップで表示

## タグカラーのサポート
- タグ名に`[#RRGGBB]`形式で色指定するとボタンの色に反映されます (例: `赤いタグ[#FF0000]`)

## プロンプト補完 (オートコンプリート)
- プロンプト欄で行頭に `#` を打つと、そのあとの文字列でタグを検索して候補を表示します
  - ポジティブ欄には `99_ネガティブ` 以外のタグ、ネガティブ欄には `99_ネガティブ` のタグだけが出ます
  - 候補は最大20件表示されます

### 操作方法

| キー | 動作 |
| --- | --- |
| `↓` / `↑` | 候補の選択を移動（端で折り返し） |
| `Enter` / `Tab` | 選択中の候補で確定 |
| `Esc` | 候補を閉じる |

- マウスでもクリックで確定できます
- 候補が出ている間の `Enter` は確定に使われます。そのまま改行したいときは `Esc` で閉じてから押してください

候補が閉じるタイミングは下記の4つです

- `Esc` を押したとき
- 候補を確定したとき
- 候補が0件になったとき
- ポップアップとプロンプト欄の外をクリックしたとき

### 検索対象

検索対象は下記の4種類です

- タグ名（日本語ラベル）
- タグの中身（英語プロンプト）
- カテゴリ名
- 確定後のコメント行と同じ `カテゴリ (タグ名)` の形式
  - 入力済みの行を打ち直すときは、そのままの形で打てば同じセクションが引けます

IMEの全角カッコ `（` と半角 `(`、大文字小文字は区別しません

### 確定時の動作

```
# 屋外          ← ここで確定すると
```
```
# 50_背景_基本:基本 (屋外),
outdoors,       ← コメント行とタグ行がまとめて挿入される
```

- 入力済みのセクションを打ち直した場合は、コメント行に続く古いタグ行ごと置き換えます
  - ただし次の行が空行かコメント行のときは、コメント行だけを置き換えます
- 確定した内容はアンドゥ（`↩️`）で元に戻せます
- 確定するとタグ情報のドロップダウンも、その行のセクションに切り替わります

### 補完に出ないタグ

テキスト挿入以外の副作用を持つため、下記は候補に出ません

- `00_テンプレート` / `90_モデル` / `96_解像度` の各カテゴリ
- `01_クオリティ:Model` / `99_ネガティブ:Model` の各グループ

## 一括生成モード

選択したタグをランダムに組み合わせながら、複数のテンプレートを順番に生成します

### 使い方

1. `00_テンプレート` タブの `99_設定` にある `一括生成モード` をONにします
   - ヘッダーの編集用UI (タグ情報のドロップダウン・上下移動・削除) が `▶ 一括生成` と進捗表示に切り替わります (どのタブに切り替えても表示され続けます)
   - プロンプト欄 (ポジティブ・ネガティブ) が読み取り専用になります。テンプレートの適用と差し替えは通常どおり行われます
   - 再読み込み・アンドゥ/リドゥ・テンプレート名・保存はそのまま使えます
2. 生成したいテンプレートのボタンをクリックして選択します (選択中は枠線が付きます)
3. 差し替えたいタグのボタン (キャラ・衣装・表情・ポーズ・背景など) をクリックして選択します
   - モードがONの間、これらのボタンは適用ではなく選択のトグルになります (プロンプト欄には何も追加されません)
   - グループの見出しボタンを押すと、配下 (サブグループを含む) をまとめて全選択／全解除できます
   - 進捗欄に `選択中: テンプレ N 件 / タグ M 件` と表示されます
   - モードをOFFにすると選択はすべてクリアされます
4. `▶ 一括生成` を押すと、選択したテンプレートを名前順に処理します (選択した順ではありません)
   - 各テンプレートで「適用 → タグの差し替え → 生成」を行います
   - 実行中は `▶ 一括生成` が `■ 停止` に切り替わります (完了・停止で元に戻ります)
   - 進捗と結果 (`完了: 成功 N 件 / 失敗 M 件`) はヘッダーに表示されます

### 組み合わせの抽選

- 選択したタグは、カテゴリ帯ごとに独立して1件ずつランダムに引かれます
  - 帯はカテゴリ先頭の番号です。`10_キャラ` と `10_キャラ_ブルアカ` は同じ帯 (`10`) なので、両方から選んでも1件だけが採用されます
- 抽選はテンプレートごとに引き直します (同じキャラが連続することもあります)
- どの組み合わせを引いたかは進捗に `1/3: <テンプレ名> ← ホシノ / セーラー服` の形で表示されます
- タグを1件も選ばなければ、差し替えなしでテンプレートのまま生成されます

### 差し替えの範囲

下記を除くすべてのカテゴリが差し替えの対象です

- `00_テンプレート` (テンプレートの選択として扱われます)
- `90_モデル` / `96_解像度` / `97_Color` / `98_特殊` / `99_ネガティブ` (テキストの挿入以外の副作用を持つため)

選択していないカテゴリのセクションは、テンプレート側の値がそのまま使われます。ネガティブプロンプトも差し替え対象外です

### 注意

- テンプレートに存在しないカテゴリは挿入されません (例: `13_衣装` のセクションを持たないテンプレートには衣装を足しません)
- 同じカテゴリのセクションがテンプレートに複数あるときは、1件目だけが差し替わり2件目以降はそのまま残ります (`33_状況` のようにテンプレート側で複数並べているものを壊さないため)
- Seed はテンプレートに保存されている値がそのまま使われます (固定Seedのテンプレートは毎回同じ絵になります)
- `■ 停止` を押すと、実行中の生成が終わった時点で打ち切ります (生成中の1枚は中断されません)
- 実行中はプロンプト欄の書き換えが競合するため、UIの操作はほぼすべて無視されます (`■ 停止` だけは受け付けます)
  - 対象: タグ・テンプレートのボタン、再読み込み、保存、アンドゥ/リドゥ、上下移動・削除、タグ情報のドロップダウン、`99_設定` の各チェックボックス
- テンプレートごとにモデルが違う場合はモデルの切り替え完了を待ってから生成します (`モデル反映` がONのとき)
- 差し替えが反映できなかったテンプレートは、元のキャラのまま生成せずに失敗として次へ進みます (詳細はブラウザのコンソールに出力されます)

## Hires CFG Scale の継承 (Forge Neo 向け)
- reForge では `Hires CFG Scale: 0` は「本体の `CFG Scale` を継承する」という意味を持ちます
  - Forge Neo にはこの仕様がなく、0 はそのまま CFG 0 として扱われてしまいます
- 本拡張機能は生成の直前に 0 を `CFG Scale` の値へ置き換えることで、reForge と同じ挙動を再現します
  - あわせて `Hires CFG Scale` スライダーの下限を 0 に緩和しています (0 を入力できるようにするため)
  - `Hires negative prompt` も編集可能にしています (継承後は 0 でもネガティブが効くため)
- `Settings` - `Easy Template Selector` の `Hires CFG Scale が 0 のとき CFG Scale を継承する (reForge 互換)` でOFFにできます
  - 反映にはブラウザの再読み込みが必要です
- 同梱テンプレートの `Hires CFG Scale` は 0 のままにしてあります。`CFG Scale` を変更すると Hires 側も追従します
  - 0 のまま保存してほしいので、テンプレートを保存するときはテンプレート適用直後の状態から行ってください
  - 生成画像のpnginfoには継承後の実値が焼き込まれます。そのため `PNG Info` から送った状態で保存すると、0 が実値のまま固定されてしまいます

## プロファイル (illustrious / anima)

モデル系統ごとにタグとテンプレートのセットを切り替えられます

- 既定は `illustrious` で、`tags/` と `templates/` の直下がそのセットです
- 同梱の `anima` プロファイルは Anima モデル向けで、`tags/anima/` と `templates/anima/` に専用のタグとテンプレートが入っています
- `tags/<プロファイル名>/` にディレクトリを作るとプロファイルとして認識され、ヘッダーのドロップダウンで切り替えられます
  - `tags/<プロファイル名>/*.yml` は同名のベースファイルを置換します。ベースに無いファイル名なら、そのプロファイル専用のカテゴリとして追加されます
  - `tags/<プロファイル名>/_exclude.yml` に stem を列挙すると、そのカテゴリを除外できます
  - テンプレートは `templates/<プロファイル名>/` 以下が使われます
- Forge Neo では UI Preset (`illustrious` / `anima` など) に同名のプロファイルがあると自動で追従します
  - 追従が効く環境ではドロップダウンは無効化されます (Preset 側が正となり、手動選択はページ再読み込みで巻き戻ります)

## anima 向けプロンプト整形

`anima` プロファイルでの生成時、生成の直前にプロンプトを自動整形します (プロンプト欄の表示は書き換えません)

- カンマの後にスペースを挿入します (Anima はスペース区切りを推奨しているため)
- `BREAK` をカンマに置換します (Anima に BREAK の仕様がないため)
- `Settings` - `Easy Template Selector` の `anima: カンマ後にスペースを自動挿入する` / `anima: BREAK をカンマに置換する` でそれぞれOFFにできます

- 生成画像のpnginfoには整形後のプロンプトが焼き込まれます。`PNG Info` から送った状態でテンプレートを保存すると、整形済みの形で固定されるので注意してください
- 整形ルールの詳細は [docs/anima-prompt-rules.md](docs/anima-prompt-rules.md) を参照してください


# UI

![UI](media/01.png)

- `🔄`: テンプレートとタグの再読み込み
- `↩️`: プロンプトの変更を元に戻す（アンドゥ）

- `⬇️`: 編集中のプロンプト行を下に移動
- `🗑️`: 編集中のプロンプト行を削除


# タグの追加

`tags`ディレクトリのファイルにタグを追加すればUIに反映されます

`tags`ディレクトリは拡張機能に同梱されており、拡張機能を更新するとタグの更新も反映されます

既存のファイルに追記するとローカルの変更が更新時に競合するので、別ファイルとして追加することを推奨します

`10_キャラ_ほげほげ.yml`のようにカテゴリIDだけ合わせると同カテゴリ扱いになり、タグ追加時に上書き対象になります

`10_キャラ_ほげほげ_.yml`のようにファイル名の末尾を`_`にすると更新の対象外になるので、ローカル専用のタグはこの形式を推奨します
